Artifacts
把想法做成能用的报告、网页和小工具

聊天记录里的一大段文字，复制出去还得重新排版；一段代码，你也不知道怎么运行。Artifact 换了个思路：Claude 直接在对话旁边给你一份“成品”，能看、能点、能改，满意了还能发给别人。

⏱ 约 16 分钟 👤 基础层所有人可读；原理层面向开发者 🎬 1 个交互演示 · 1 张图示

学完这一课，你能

  • 说出 Artifact 能做哪几类东西，以及什么时候适合用它
  • 用一段清楚的需求描述，让 Claude 做出可用的初版
  • 用“一次改一两处”的方法把初版迭代成你想要的样子
  • 分享或公开之前，检查访问范围和里面的数据
  • （开发者）了解 Artifact 的存储、连接应用等能力边界，以及 Claude Code 中的对应功能

一句话总结

Artifact 是 Claude 在对话旁边单独做出来的成品；先要一个能用的初版，再一处一处地改，分享之前想清楚谁能看到、里面存了什么。

01Artifact 是什么

先看一个例子：你请 Claude 列一份旅行打包清单，清单没有挤在聊天气泡里，而是在对话旁边的一个独立窗口里打开，可以勾选、可以接着改，下次还能找到。

当 Claude 要给你的内容比较完整、能独立存在、而且你多半会反复使用时，就会这样单独放进一个窗口。这个窗口里的东西，就是 Artifact。

🧩
打个比方：边聊边画的白板

和设计师开会时，你们一边说话，他一边在白板上画稿。稿子单独立在那儿，你可以指着说“这个按钮大一点”，他擦掉重画。对话是你们的交流，白板上的稿子才是成果。

截至 2026-11，按官方帮助中心，Artifact 可以是：

类型适合做什么例子
文档需要排版、会被转发的文字调研报告、活动方案、操作说明
演示文稿要讲给别人听的内容家长会分享、周会汇报
单页网页需要好看地展示的信息活动介绍页、个人作品页
图表与示意图把数字和流程画出来月度开支饼图、办事流程图
交互小工具需要点、填、算的东西记账本、家务积分表、倒计时

此外还有文档、幻灯片、设计等现成模板，部分模板可以导出成 Word、PDF、PowerPoint 等格式。你做过的 Artifact 都会保存在侧栏的 Artifacts 里，换一段对话也能找回来。哪些模板在你的套餐里可用、是否为 beta，以官方帮助中心为准。

下面的演示把一句口语化的需求做成“家务积分表”。注意两个细节：Claude 先给了一个能用的简单版本；第二轮涉及“存数据、全家共用”时，它先想清楚了谁能看到这些数据。

03怎么提需求，怎么一步步改

做 Artifact 和做别的事一样，第一句话说清楚，能省掉很多来回。一个好的需求通常回答这几件事：

  1. 做给谁用：自己、家人、同事，还是公开的读者？
  2. 要做成什么：文档、网页、小工具、图表？
  3. 最核心的一两个功能：先说最重要的，别一口气列二十条。
  4. 手头有什么材料：数据、文字、你喜欢的样例。
帮我做一个记录每天喝水量的小工具，给我自己用，主要在手机上打开。功能：点一下按钮记一杯（250 毫升），显示今天喝了多少、离 2000 毫升还差多少。先做最简单能用的版本，界面清爽一点。

初版出来之后，按下面的节奏迭代：

  • 先试用，再提意见：点一点、填一填，比盯着看更容易发现问题。
  • 一次改一两处：“按钮改成蓝色、字大一号”比“整体再好看一点”更容易改对。
  • 描述你看到的现象：“点了记一杯，数字没变”比“坏了”有用得多。
  • 小改动可以自己动手：文档、幻灯片这类模板可以直接在里面编辑；选中一段文字，也可以只让 Claude 改这一段。
  • 报错时让它修：小工具出错时，界面上通常有“让 Claude 尝试修复”的入口，但不保证一次修好，修不好就把出错的现象描述给它。
  • 想回到之前的思路：编辑前面的某条消息会开出一条新的对话分支，原来的版本不会丢。
💡
内容要准确的，自己核对

报告里的数字、网页上的日期和地址，Claude 可能写错。Artifact 看起来越“像成品”，越容易让人放松警惕。发出去之前，关键信息逐条核对一遍。

04让小工具“活”起来：存数据、连应用、用上 Claude

截至 2026-11，新版 Artifact 不只是静态页面，还能做到下面这些事。按官方帮助中心，存储数据和连接应用面向付费套餐（Pro 及以上），在网页版和桌面版可用。

能力能做什么要注意什么
个人存储记住你自己的数据，比如日记、喝水记录只有你自己看得到
共享存储所有使用者看到同一份数据，比如家务积分、排行榜所有能打开它的人都能看到；第一次使用会弹出确认；不要放敏感信息
连接应用读写你已连接的日历、任务表等（第 6 课的连接器）第一次使用要你批准；每个使用者用的是自己的连接，看不到你的数据
调用 Claude做一个会“思考”的小工具，比如帮孩子出口算题使用者用自己的账号登录，用量算在各自的套餐里；第一次需要授权

官方原话说得很直白：存储用个人的还是共享的，由做 Artifact 的人决定。所以在别人做的 Artifact 里输入任何敏感信息之前，先确认它用的是不是共享存储。

原理层Artifact 的边界与 Claude Code 里的对应功能▾
  • 前提：Artifact 依赖“创建和编辑文件”（旧称“代码执行与文件创建”）能力，个人套餐默认开启；团队版和企业版由组织设置控制。
  • 存储限制（截至 2026-11）：每个 Artifact 的存储上限 20 MB，只能存文本，不能存图片、文件或二进制数据。
  • 连接应用的限制：要求“每次操作都审批”的连接器工具不能在 Artifact 里使用；组织管理员可以整体关闭这项能力。
  • 旧版 Artifact：2026 年 9 月 16 日之前在对话中创建的属于旧版，仍可使用、发布和分享，但不能再新建同类；旧版的存储要发布后才能用，取消发布会永久删除其中的数据。
  • Claude Code：可以把会话产出发布成一个可交互的页面（私有链接，随会话更新），也可以做设计稿和文档。和应用里一样，它默认只有你自己可见，分享范围受套餐和组织设置限制，以 Claude Code 文档为准。

这些细节变化很快，用之前以官方帮助中心和 Claude Code 文档为准。把 Artifact 当成“别人写的程序”来看待：打开来源不明的 Artifact 或复制别人的代码，与打开陌生人发来的文件一样需要谨慎。

05分享与发布：先想清楚谁能看到

新做的 Artifact 默认只有你自己能看到。要给别人看，需要你主动在“分享”里设置访问范围。截至 2026-11，按官方帮助中心：

套餐可选的访问范围
个人套餐（Pro、Max、Ultra 等）仅自己；知道链接的任何人；按邮箱邀请指定的人（beta）
团队版、企业版仅受邀的人；组织内所有人；知道链接的任何人（需要管理员开启对外分享）

还可以给不同的人设置“仅查看”“可评论”“可编辑”等权限。“知道链接的任何人”多数情况下不需要登录就能打开（例外：文档类 Artifact 即使这样设置，也要登录才能查看），所以链接一旦发到群里，就要当成公开内容对待。

⚠️
分享前的五个检查
  1. 内容里有没有隐私：真实姓名、手机号、住址、孩子学校、账户信息？
  2. 用的是哪种存储：共享存储里的数据，所有打开的人都能看到。
  3. 范围是不是刚好：给家人看就别选“任何人”，团队内部的就别对外。
  4. 旧版 Artifact 会带出附件：分享 2026 年 9 月之前在对话里做的旧版 Artifact 时，对方可能还能看到那段对话里上传的附件和文件，先检查附件里有没有敏感内容。
  5. 不用了记得收回：把访问范围改回“仅自己”（团队版为“仅受邀的人”）即可停止分享。

另外，手机 App 上可以创建、查看和编辑 Artifact，但分享设置需要在网页版或桌面版里操作。

06动手试一试

🛠 三轮对话做一个小工具 不需要写代码
  1. 用第 03 节的格式描述一个你真的会用的小工具，比如：
    帮我做一个旅行打包清单小工具：按“证件 / 衣物 / 电子产品 / 洗漱”分类，可以勾选已打包的物品，显示还剩几件没装。先做最简单的版本。
  2. 试用初版，挑出最想改的一处，告诉 Claude 你看到的现象和期望的样子。
  3. 再改一轮。改完后数一数：你一共提了几次修改？哪次说得最清楚、改得最准？
  4. 如果想发给同行的人，先过一遍第 05 节的“分享前的五个检查”。
📊 把一段数据画成图表 不需要写代码
下面是我家这半年每月的电费（元）：1 月 210，2 月 236，3 月 180，4 月 150，5 月 160，6 月 260。做一个柱状图，标出最高和最低的月份，并用一两句话说说可能的原因（我家夏天开空调、冬天用电暖器）。

做完后检查：图上的数字和你给的是否一致？Claude 的“原因”是推测还是事实？

07常见误区

✗

需求要一次写全，不然做出来就不对。

✓

先要一个能用的简单版，再一处一处改，通常比一次写几十条要求更快得到满意的结果。

✗

Artifact 做出来就默认公开了。

✓

新的 Artifact 默认只有你自己能看到，要你主动设置分享范围才会给别人看。

✗

看起来像成品，内容就一定是对的。

✓

排版漂亮不等于信息准确。数字、日期、地址等关键信息要自己核对。

08小测验

Q1初版小工具的按钮点了没反应，下面哪种说法最能帮 Claude 改对？
说清楚“做了什么、看到了什么、期望什么”，Claude 才知道问题出在哪。笼统的评价只会让它乱猜。
Q2你做了一个全家共用的积分表，用的是共享存储。下面哪条信息最不该写进去？
共享存储里的内容，所有能打开这个 Artifact 的人都看得到。密码、证件号这类信息不该出现在任何分享出去的东西里。

09推荐工具与延伸

Artifact 的大部分能力不需要额外安装。想让 Claude 生成格式更规范的 Word、表格、演示文稿，可以参考第 7 课提到的官方 Skills 示例库。卡片上的“核实于”日期，是最后一次检查维护状态和许可证的时间。
