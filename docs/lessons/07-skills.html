Skills
让 Claude 学会你的固定流程

每周写周报，你都要重新交代一遍：“分三部分，每部分最多三条，语气直接一点……”说了十次，第十一次还得再说。Skills 的作用，就是把这些“每次都要讲的话”写成一本手册，交给 Claude 放在书架上，用到时它自己翻开。

学完这一课，你能

  • 说清楚 Skill 是什么，以及它和提示词、Projects、连接器各管什么
  • 判断哪些事情值得做成 Skill
  • 启用内置 Skills，并亲手做出一个自己的 Skill
  • 知道安装别人的 Skill 前要检查什么
  • （开发者）看懂 SKILL.md 的结构和渐进式加载，在 Claude Code 里创建和调用 Skill
