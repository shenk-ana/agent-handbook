权限模式、CLAUDE.md 与记忆
给 Claude Code 定规矩

新同事入职，你会告诉他两类事：哪些事可以自己拍板、哪些必须先问你；还有这个项目的“老规矩”。Claude Code 也一样。前一类靠权限模式和权限规则，后一类靠 CLAUDE.md 和记忆。这一课把两类规矩都讲清楚。

学完这一课，你能

  • 分清“锁”（权限，由 Claude Code 程序强制执行）和“须知”（说明，由 Claude 参考执行）两类规矩
  • 说出六种权限模式各自放行什么、适合什么场景
  • （开发者）读懂 settings.json 的层级，写出正确的 allow / ask / deny 规则
  • （开发者）写一份精简有效的 CLAUDE.md，知道什么该写、什么不该写
  • （开发者）用 /memory 管理自动记忆，理解工作区信任挡住了什么
