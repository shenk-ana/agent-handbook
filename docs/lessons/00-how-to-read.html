01这本书讲什么

这是一本讲 Agent 的书。Agent 是一种能自己动手办事的 AI：你交代一件事，它会自己查资料、用工具、看结果，再决定下一步，直到把事办完。

书里所有例子都用 Claude。Claude 是 Anthropic 公司做的 AI，有网页、手机和电脑上的 Claude 应用，也有给程序员用的 Claude Code。选一个具体的产品来讲，例子才能落到实处。你学到的思路，换成别的 AI 产品也大多适用。

这本书不是产品说明书。按钮在哪、套餐多少钱这类信息变得很快，书里只在必要时提一句，并且标明时间。我们更关心那些不太会变的东西：Agent 能做什么、做不好什么、怎么和它合作。

03基础层和原理层

每一课都写给两类读者，用同一个页面的两层内容：

  • 基础层：就是你现在读的正文。大白话、生活例子，不出现代码。只读这一层，也能读懂每一课的核心意思。
  • 原理层：灰色边框、带“原理层”标签的折叠框。写给开发者，讲背后是怎么回事，会出现术语和少量代码。

页面顶部有一个“基础 / 原理”开关。选“原理”，本页所有原理层会一起展开；选“基础”，它们会收起来。你也可以只点开某一个框。这个选择会被记住，翻到下一课也一样。

原理层这就是一个原理层：给开发者的阅读建议▾

本书的开发者读者，主要是每天在用 Claude Code 的人：命令行（CLI）、桌面应用里的 Code、VS Code 或 JetBrains 插件、网页版。原理层的讲法有固定顺序：

  1. 先讲这个原理在 Claude Code 里表现为什么：界面上看到什么、对应哪个命令或配置；
  2. 再讲你怎么利用或干预它：权限、CLAUDE.md、/context、Hooks、Subagents、MCP 等；
  3. 最后才讲底层机制：Messages API 的结构、论文出处。

调用 API、写 SDK 代码的内容会标明“日常使用 Claude Code 可以跳过”。Claude Code 的命令和界面文字随版本变化，书里点到为止，一切以 /help 和官方文档为准。

04不懂的词，点一下

正文里带虚线下划线的词，比如 上下文窗口，是书里的术语。把鼠标移上去，或者在手机上点一下，就会弹出一张小卡片：先是一句大白话，再是一个生活中的比方。打开“原理”开关后，卡片里还会多一条技术定义。

所有术语都收在顶栏“百科”里，也就是附录 A。读到后面忘了前面的词，随时可以去查。

05演示播放器怎么看

书里很多地方会放一个“演示播放器”，把 Claude 办一件事的过程一步步放给你看。先用下面这个小例子熟悉一下操作：

你想做什么怎么操作
播放 / 暂停点底部的播放按钮（电脑上也可以先点一下播放器，再按空格键）
一步一步看点底部向右的箭头按钮前进，向左的箭头后退（电脑上也可以按 → 和 ← 键）
跳到某一步点底部那排小圆点中的任意一个
看懂这一步在干什么读循环图旁边的“旁白”（手机上在对话下方）
看底层传了什么消息点右上角的“API 视角”，给好奇的人和开发者看
放慢或加快底部最右边的倍速选择（很窄的手机屏幕上会隐藏）

演示里的圆环叫“Agent 循环图”（电脑上在右边，手机上在对话下方）。紫色是思考，琥珀色是行动，青绿色是观察。全书讲到循环时都用这三种颜色。循环图下方的“上下文占用”条，表示 Claude 的“桌面”被占了多少，第 5 课会细讲。

有些演示会换成黑底的终端样式，那是在模拟程序员用的 Claude Code。操作方法一样。

06两个重要的提醒

📅
资料截至 2026 年 11 月

AI 产品更新很快。书里提到的产品名称、功能、可用平台，都在写作时对照过 Anthropic 官方资料，但之后可能变化。遇到“截至 2026-11”的字样，说明这条信息特别容易变。用之前，以官方帮助中心和产品界面为准。

全书的约定：菜单和设置项写中文名，第一次出现时在括号里注上英文界面名。不同版本、不同语言的界面叫法可能不一样，一律以你看到的界面为准。

🎬
演示是“录好的回放”，不是真的在调用 Claude

播放器里的每一步都是预先写好的脚本。它不会联网，不会调用任何服务，也不收集你的数据。演示里的餐厅、城市、网址很多是虚构的，界面是自己画的示意图，和真实产品的样子会有出入。它的作用是把“看不见的过程”放慢给你看。

07动手试一试

🧭 熟悉页面上的三样工具 不需要写代码
  1. 点一下顶栏的“原理”，看看第 03 节的折叠框有没有展开；再点“基础”收起来。
  2. 把鼠标移到第 04 节的“上下文窗口”上（手机上点一下），读一读弹出的卡片。
  3. 回到第 05 节的演示，不按播放，只点向右的箭头按钮（电脑上也可以按 → 键）一步一步看完。好奇的话切到“API 视角”看一眼第 3 步，看不懂也没关系。
  4. 在第 02 节的地图里选出你的路线，记下你下一课要读哪一课。

08常见误区

✗

原理层太难，跳过就会漏掉重点。

✓

基础层本身是完整的。原理层是“加深”，不是“补全”，不写代码的读者可以不看。

✗

演示里显示的就是 Claude 真实的回答。

✓

演示是预先写好的脚本，用来说明过程。真实的 Claude 每次的做法和措辞都可能不同。

✗

书里写的按钮位置一定和我看到的一样。

✓

界面会更新。书里尽量只写“在设置中可以……”，具体位置以你看到的产品界面和官方帮助为准。

09小测验

Q1你不写代码，只想在工作和生活中用好 Claude。最适合的路线是？
第 1、2 部分就是为普通用户写的。第 3、4 部分面向开发者，可以以后有兴趣再看。
Q2书里的演示播放器在做什么？
演示不联网、不调用任何服务，界面也是自己画的。它展示的是“过程长什么样”。
Q3在演示的循环图里，琥珀色亮起表示 Claude 在做什么？
紫色是思考，琥珀色是行动，青绿色是观察。全书讲到循环时都用这三种颜色。
