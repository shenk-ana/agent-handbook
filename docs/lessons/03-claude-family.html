该用哪个

网页版、手机 App、桌面应用、Cowork、Claude in Chrome、Claude Code、API……名字一多，就容易犯迷糊。其实它们背后是同一组模型，区别在于“你在哪里用”和“允许它碰什么”。这一课帮你画一张地图，再用一个小工具帮你挑。

⏱ 约 15 分钟 👤 所有人；原理层面向开发者 🎬 1 个交互选择器

学完这一课，你能

  • 说出 Claude 有哪几种产品形态，各适合做什么
  • 根据自己要做的事，挑出合适的产品
  • 理解 Fable、Opus、Sonnet、Haiku 几个模型的定位差别
  • （开发者）分清 Claude Code 各形态、Claude API、Agent SDK 和 Managed Agents 的关系

一句话总结

日常聊天用 Claude 应用；要它替你动电脑文件或网页，用 Cowork 或 Claude in Chrome；写代码用 Claude Code。模型按“聪明、快、省”来挑。

Claude 应用像你和助理面对面开会，你递资料、他给建议。Cowork 和 Claude in Chrome 像把助理请到你的办公桌和电脑前，让他直接上手。Claude Code 像让他进你的工作室，直接动手改你正在做的作品。API 则是把这位助理“借调”到你自己的公司去上班。

02逐个认识

Claude 应用：网页、桌面、手机

大多数人的起点。在浏览器打开 claude.ai，或者安装电脑版和手机版（iOS、Android）。同一个账号的对话在各端同步。

除了聊天，它还能网页搜索并给出处、读你上传的文件和图片、用 Projects 管理长期资料（第 5 课）、生成 Artifacts（第 8 课）、通过连接器接入你的日历和网盘等服务（第 6 课）。免费账号就能用，部分功能需要付费套餐。

Claude Cowork：替你在电脑上办事

Cowork 把 Claude Code 背后的 Agent 能力，用在写代码以外的工作上：整理文件、做文档和表格、汇总资料。你不用碰命令行。在桌面应用里，它可以读写你连接的文件夹；在网页和手机上也能使用，但部分功能只在桌面端有。截至 2026-11 需要付费套餐。

Claude in Chrome：在浏览器里动手

一个 Chrome 浏览器扩展。它能让 Claude 阅读网页、点击、输入、填写表单，任务可以从浏览器侧边栏、Cowork 或 Claude Code 里发起。截至 2026-11 需要付费套餐，只支持电脑上的 Google Chrome，不支持其他浏览器和手机。官方特别提醒：让 AI 直接操作网站有风险，第 9 课会讲怎么安全使用。

Claude Code：写代码的 Agent

给程序员用的 Agent，能读写项目文件、运行程序。不写代码的你可以跳过，第 3 部分（第 11～14 课）专门讲。

Claude API 与 Agent SDK：自己造

给程序员把 Claude 接进自己的产品。Claude API 让你的代码直接调用模型，按用量计费；Claude Agent SDK 把 Claude Code 那一套循环、工具和权限做成了代码库。普通用户用不到它们，知道有这回事就好。

📅

原理层开发者怎么选 Claude Code 的形态▾

Claude Code 有终端 CLI、桌面应用里的 Code、IDE 插件（VS Code，以及 Cursor 等 VS Code 分支；JetBrains 系列）和网页版（claude.ai/code）几种形态。使用它需要 Claude 订阅或 Anthropic Console（开发者平台）账号；桌面应用里的 Code 需要付费订阅。

各形态连接的是同一个 Claude Code 引擎，所以仓库里的 CLAUDE.md、设置文件和 MCP 服务器配置在各处都能用。选择主要看工作习惯：

形态适合备注
终端 CLI日常主力、脚本化（claude -p 非交互模式可以接管道和 CI）功能最全，新特性通常最先到这里
桌面应用的 Code想直观地审改动、并行跑多个会话、设置定时任务内置 Claude Code，不必另装 CLI；需要付费订阅
VS Code / JetBrains不想离开编辑器，要内联 diff 和选区上下文JetBrains 插件依赖单独安装的 CLI
网页版 claude.ai/code本地没有仓库、长任务、并行任务，用手机跟进在云端环境运行，可以再拉回本地终端继续

此外还有 GitHub Actions / GitLab CI 集成、Slack 中 @Claude、Chrome 扩展调试网页等接入方式。命令和入口随版本变化，以 /help 和官方文档（code.claude.com）为准。

原理层API、Client SDK、Agent SDK、Managed Agents 的分工▾

想“自己造”时，有四个容易混淆的名字。区别在于谁来跑循环、自带什么工具、跑在哪里：

  • Client SDK（如 Python 的 anthropic 包）：直接调用 Claude API。工具循环你自己写，或者用 SDK 里的 beta 版 Tool Runner。
  • Claude Agent SDK（Python / TypeScript）：把 Claude Code 的 Agent 当作库嵌进你的程序，自带读写文件、执行命令、搜索网页等内置工具，以及权限、会话、Hooks、Subagents 和 MCP。运行在你自己管理的进程里。
  • Managed Agents：由 Anthropic 托管的 Agent 运行环境，通过 Claude API 配置，会话跑在托管沙箱（或你自己的沙箱）里。
  • Claude Code CLI 的 -p 模式：用其他语言驱动同一个循环时，可以把 CLI 当子进程调用。

第 15 课用 Client SDK 手写了一个循环，第 22 课会把 Agent SDK 和 Managed Agents 展开讲。

04模型家族：聪明、快、省之间的取舍

不管用哪个产品，背后都是 Claude 模型。Claude 不是只有一个模型，而是一个模型家族。截至 2026-11，Anthropic 公布的当前模型有四条线：

模型定位速度适合
Claude Fable 5.1最强的推理能力，面向长时间、高难度的 Agent 任务较慢非常复杂、要连续工作很久的任务
Claude Opus 5.5大多数工作，官方建议先从它开始；擅长长时间的编程和知识工作中等拿不准时先用它
Claude Sonnet 5.5速度和智能的最佳平衡快日常的大量工作，要求响应快
Claude Haiku 5.5最快，适合大批量、要求即时响应的简单任务最快分类、提取信息、分流

普通用户怎么选？大多数时候用默认的就行。遇到特别难的问题，比如复杂的分析或长篇写作，可以在模型选择器里换一个更强的模型。截至 2026-11，当前模型在回答前都会先“想一想”，也就是思考模式，这一步在应用里不能关闭。哪些模型可选，取决于你的套餐，以界面上的模型选择器为准。

除了这四个，还有限量开放的型号（如 Mythos）和仍可使用的旧版本，以官方模型页为准。

模型更新很快，名字和版本号每隔几个月就会变。记住“更强、更快、更省”这三种取舍，比记住某个版本号更有用。

原理层在 Claude Code 和 API 里指定模型▾
  • Claude Code：用 /model 切换模型并保存为默认；在支持的模型上可以调整 effort（推理投入的档位），也有 /effort 命令。复杂重构用更强的模型、更高的 effort，简单的批量修改可以换快一些的模型。
  • API 模型 ID：claude-fable-5-1、claude-opus-5-5、claude-sonnet-5-5、claude-haiku-5-5。从 4.6 代开始，不带日期的 ID 本身就是固定快照。四个模型都有 1M token 的上下文窗口，输出上限 128K token（同步 Messages API）。
  • 思考：当前模型使用 adaptive thinking，由模型根据 effort 自己决定想多少；早期模型上手动指定 budget_tokens 的 extended thinking 在新模型上已不再接受。Fable 5.1 和 Opus 5.5 的 adaptive thinking 始终开启。
  • 能力查询：Models API 会返回每个模型的 max_input_tokens、max_tokens 和 capabilities，按 line 字段分组，比从 ID 字符串里猜更可靠。

以上以 Anthropic 官方 Models overview 为准（截至 2026-11）。

06常见误区

✗

网页版、手机版、Claude Code 是三个不同的 AI。

✓

它们背后是同一组 Claude 模型。区别在于界面和它被允许使用的工具。

✗

Claude Code 只有命令行，不会用终端就用不了。

✓

还有桌面应用里的 Code、IDE 插件和网页版。不写代码、只想整理文件和文档的人，更适合 Cowork。

✗

选最强的模型总不会错。

✓

更强的模型往往更慢、消耗的用量更多。简单的事用快一些的模型，体验反而更好。

07小测验

Q1你不会写代码，想让 Claude 把电脑里一个文件夹的几十份发票整理成一张表格。最合适的是？
Cowork 面向不写代码的人，可以处理你连接的文件夹、生成表格。API 和 CLI 都需要编程或命令行基础。
Q2想让 Claude 替你在网页上填一份报名表，应该用哪个产品？
Claude in Chrome 是浏览器扩展，能让 Claude 在网页上阅读、点击和填表。截至 2026-11 它需要付费套餐，只支持电脑上的 Google Chrome。填表前先确认要填的内容，提交前自己看一眼。
Q3你要让 Claude 给成千上万条用户留言自动分类，要求快、量大。哪个模型的定位最符合？
Haiku 定位于大批量、要求即时响应的任务，比如分类、提取和分流。Fable 适合高难度的长任务。
Q4（开发者）你想在自己的 Python 服务里嵌入一个能读写文件、执行命令的 Agent，并复用 Claude Code 的权限和 Hooks。应该用？
Agent SDK 就是“作为库的 Claude Code”，自带内置工具、权限、会话和 Hooks。手写循环需要自己实现这些。
