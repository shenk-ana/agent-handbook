多 Agent 系统
什么时候该“组队”，什么时候不该

一个人做调研，要先查甲、再查乙、再翻自家资料，桌上越堆越乱。换成一个小组：三个人各查一块，组长只看三份摘要。多 Agent 系统就是这个思路。它很好用，但也很贵，这一课讲清楚两面。
