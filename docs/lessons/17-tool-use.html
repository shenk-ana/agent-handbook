工具调用与 MCP
Claude 是怎么“看懂”一个工具的

第 15 课说，Claude 的“行动”就是写一张格式严格的单子，由程序替它去办。那它怎么知道有哪些单子可以开、每张单子该怎么填？答案是工具的“说明书”。这一课拆开这份说明书，再看 MCP 协议如何把别人写的工具接到 Claude 身上。
