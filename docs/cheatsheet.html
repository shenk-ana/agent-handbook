速查卡

把全书最常翻的东西收在一页里：写任务简报、做安全检查、找 Claude 的入口、查 Claude Code 的命令。每张卡片都注明了对应的课，想看原理就回到那一课。前三张卡给所有人，第 4 到第 6 张给 Claude Code 使用者，第 7 张是术语速记。

🖨 可以直接打印（电脑上按 Ctrl+P 或 Cmd+P） 命令与界面会随版本变化，以 /help、界面和官方文档为准

1 · 任务简报六部分模板

对应：第 4 课、第 10 课。把括号里的内容换成你自己的。每一行都建议保留，不确定的写“暂无”。

目标：（一句话说清要做成什么） 背景：（为什么做、给谁用、已有的资料或前提） 限制（含不许做的事）：（范围、风格、时间；不许做的事，例如“只起草，不要发送”“不要删除任何文件”） 交付：（交付什么、做成什么样子：几页、什么格式、放在哪里） 完成标准：（怎样算做好了，例如“每个结论都有来源”） 先问我：有不清楚的地方先问我；发送、提交、付款、删除之前，也先停下来问我。

2 · 交给 Agent 前的安全清单（精简版）

对应：第 9 课（完整可勾选版）；威胁建模见第 21 课

  • 只开这次要用的连接器和工具，用完关掉
  • 对话和文件里没有密码、验证码、证件号、银行卡号
  • 能只读完成的任务，不开写入权限
  • 付款、发送、删除、改设置，保持每次确认
  • 连接器、Skill、扩展都来自可信来源
  • 简报里写明“不要做什么”
  • 它读到的网页或邮件里出现“冲着 AI 说的话”，停下来看一看
  • 知道怎么停下它、撤销授权；完成后看一遍它实际做了什么

4 · Claude Code 常用命令与快捷键 （开发者）

对应：第 11 课、第 12 课、第 16 课；安全相关见第 9 课。表中命令均对照 code.claude.com 官方文档；键盘快捷键按“电脑上”的写法，Mac 的 Option 键需在终端里设为 Meta。

斜杠命令（在会话里输入 /）

命令作用
/help显示帮助和可用命令
/init为项目生成初始的 CLAUDE.md
/memory编辑 CLAUDE.md，开关自动记忆，查看自动记忆条目
/clear开始一段上下文为空的新对话（别名 /reset、/new）
/compact把到目前为止的对话总结压缩，腾出上下文；可附带要保留重点的说明
/context用彩色网格看上下文用量，并给出优化建议
/model切换模型，并保存为新会话的默认值
/permissions管理允许、询问、拒绝规则（别名 /allowed-tools）
/plan直接进入计划模式，可附带任务描述
/mcp管理 MCP 服务器的连接和 OAuth 授权
/rewind把对话和代码回退到之前的点（别名 /checkpoint、/undo）
/resume回到之前的某段对话
/usage查看会话花费、套餐用量与统计（/cost 是别名）
/status查看版本、模型、账号、连接状态和已加载的设置来源
/background把当前会话转到后台运行（别名 /bg）
/doctor检查安装和配置问题并给出修复建议

快捷键与输入方式（电脑上）

按键 / 输入作用
Esc中断 Claude 当前的回答或工具调用，已做的工作保留
Esc 连按两次输入框有字时清空草稿；输入框为空时打开回退菜单
Shift+Tab循环切换权限模式
Ctrl+C中断；没有任务在跑时，第一次清空输入，第二次退出
Ctrl+D退出会话（需要确认）
Ctrl+O打开 / 关闭转录视图，查看详细的工具调用
Ctrl+B把正在运行的 Bash 命令或 agent 放到后台
Ctrl+R反向搜索历史输入
Ctrl+G在默认文本编辑器里编辑当前输入
Option+P（Mac）/ Alt+P切换模型，不清空已输入的内容
/ 开头命令或 Skill
! 开头直接运行一条 shell 命令，并把输出加入会话
@文件路径自动补全
\ + Enter在输入框里换行，所有终端都可用

更多命令（例如 /hooks、/agents、/loop、/schedule、/chrome）见第 13 课与第 23 课；以 /help 为准。

5 · Claude Code 权限模式一览 （开发者）

对应：第 9 课、第 12 课。共六种，界面文字以实际版本为准。按 Shift+Tab 在可用的模式间循环（不询问模式不在循环里，跳过权限模式必须在启动时启用）。

中文名（界面英文）配置值不用问就能做的事
手动模式（Manual）default只读操作
自动接受编辑模式（Accept edits）acceptEdits读、改文件，以及工作目录内的 mkdir、touch、rm、rmdir、mv、cp、sed 等文件命令。注意 rm 会删文件，批准前先确认目录
计划模式（Plan）plan只读；改动要等你批准计划之后
自动模式（Auto）auto几乎所有操作自动进行，每一步先由另一个模型检查是否越界
不询问模式（不在模式指示器中显示）dontAsk只读和预先批准的工具；其余需要询问的一律拒绝
跳过权限模式（Bypass permissions）bypassPermissions跳过几乎所有确认（仅限隔离环境）

默认值：新版交互式终端和 VS Code 默认从自动模式起步（v2.1.283 起）；claude -p 和 Agent SDK 默认是手动模式（default）。拒绝规则（deny）在所有模式下都生效。启动时指定：claude --permission-mode plan。

6 · 常用配置文件位置 （开发者）

对应：第 12 课、第 13 课、第 14 课。“项目”指项目文件夹里的 .claude，“个人”指你主目录里的 ~/.claude（Windows 上是 %USERPROFILE%\.claude）。

文件位置用来做什么
CLAUDE.md项目根目录；个人在 ~/.claude/CLAUDE.md每次会话都加载的说明和约定。个人私用的写进项目根目录的 CLAUDE.local.md（需自己加入 .gitignore）
settings.json个人：~/.claude/settings.json；项目共享：.claude/settings.json权限规则、hooks、环境变量、默认模型。严格 JSON，不能有注释
settings.local.json.claude/settings.local.json只对你自己、只在这个项目生效，不提交到 Git
.mcp.json项目根目录团队共享的 MCP 服务器；个人的 MCP 服务器记在 ~/.claude.json
agents/*.md.claude/agents/ 或 ~/.claude/agents/Subagent 定义
skills/<名字>/SKILL.md.claude/skills/ 或 ~/.claude/skills/可用 /名字 调用或自动加载的 Skill

多个来源设了同一个键时，优先级从高到低：组织托管设置、命令行 --settings、项目本地、项目共享、个人。运行 /status 可以看到哪些来源已加载。

7 · 术语速记

对应：第 1 课、第 15 课 等。点术语名跳到 附录 A 的完整解释。

  • Agent：能自己拆任务、调工具、看结果，直到办完的 AI
  • Agent 循环：想 → 做 → 看，转圈直到完成
  • 工具调用：模型提出要用哪个工具，由程序去执行
  • MCP：把外部服务接给 AI 的统一标准
  • 连接器：Claude 应用里的 MCP 服务器
  • Skill：教 Claude 一套固定流程的说明包
  • 上下文窗口：模型一次能“看到”的内容总量
  • token：模型处理文字的计量单位
  • 上下文压缩：把前面的内容总结成摘要腾出空间
  • 幻觉：说得头头是道，但内容是错的
  • 提示注入：藏在内容里、冲着 AI 说的假“指令”
  • 最小权限：只给刚好够用的权限
  • 人在回路：关键步骤由人确认
  • 权限模式：Claude Code 做事前问不问你的档位
  • CLAUDE.md：写给 Claude Code 的项目说明
  • 子 Agent（Subagents）：独立上下文里干活的子 Agent
  • Hooks：在固定时点自动运行的脚本
  • Artifacts：Claude 做出来的可预览成品
  • 任务简报：写给 Agent 的六部分完整说明
